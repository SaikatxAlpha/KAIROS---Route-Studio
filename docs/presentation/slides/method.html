Reliability-aware planning

The cheapest plan that meets a reliability target

01

Scenario model

Day, vehicle, arc and service noise; estimated arcs carry model error

02

Buffer ladder

PyVRP solves with durations mean + β·sd, β = 0 … 2, warm-started

03

In-sample test

Each candidate is simulated on 100 planning scenarios

04

Chance constraint

Keep the cheapest candidate whose on-time rate ≥ target

05

Out-of-sample

Scored on unseen scenarios, common random numbers

Same PyVRP iteration budget for every planner. The target slider is the right-hand side of the chance constraint, so it changes which plan is chosen, not a label.

Ablations: quantile buffer alone (one solve at z·sd) and scenario selection alone (five unbuffered solves)

A sample-average approximation of a chance constraint. Buffers alone over-protect; selection alone has nothing safer to choose from. The ladder gives the selection a spectrum from cheap to safe, and the target picks the point on it. Integer rounding is conservative so solver feasibility implies simulator feasibility.
