## Experiment 6 — travel-time estimation with calibrated uncertainty (real Amazon data)

Train dates 2018-07-19–2018-08-14, calibration 2018-08-15–2018-08-20, test 2018-08-21–2018-08-26; 1,200,000 / 348,779 / 143,585 arcs.

| Metric (test dates) | LightGBM + CQR | Per-station speed fit |
|---|---:|---:|
| MAE | 54.3 s | 61.9 s |
| Median absolute % error | 14.3% | 16.1% |
| 50% interval: coverage (raw → conformal) / width | 48.5% → 49.7% / ×1.34 | 48.1% / ×1.35 |
| 80% interval: coverage (raw → conformal) / width | 78.8% → 80.2% / ×1.76 | 78.5% / ×1.90 |
| 90% interval: coverage (raw → conformal) / width | 88.9% → 90.2% / ×2.09 | 89.2% / ×2.46 |
| 95% interval: coverage (raw → conformal) / width | 94.2% → 95.2% / ×2.45 | 94.7% / ×3.26 |

Caveats: Arcs within one route are dependent; coverage is marginal over arcs and assumes exchangeability between the calibration and test date blocks. The interval quantifies uncertainty in the average travel time of an unobserved stop pair, not day-to-day variability of individual trips (the dataset has no per-trip observations).
